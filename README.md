# 肾友食养助手

基于国家卫生健康委《成人慢性肾脏病食养指南（2024年版）》的响应式网页工具，一套代码适配手机、iPad mini 和电脑。

## 功能

- 用户档案：地区、疾病分期、身高体重、活动量、性别、监测指标、现有食材（仅存本机浏览器）
- 规则推荐：按指标（血钾/血磷/血钠/尿酸/白蛋白/血红蛋白）、地区、现有食材生成菜谱；只排除“慎用”菜谱并按低钾/低磷优先排序，支持替代食材匹配
- 推荐分组：列表默认按“可直接做 > 差 1–2 个食材 > 需备齐更多食材”展示
- 菜谱详情：食材用量、分步做法、营养估算（参考）、替代食材、注意事项、适用分期
- 每日营养需求：按指南附录5 表5.2 口径计算能量、蛋白质、钠、钾、磷、钙、铁、水目标
- 今日配餐：早/午/晚/加餐，智能配餐与手动换菜，累计营养对照
- 收藏、历史：浏览器本地存储，无需登录
- 服药/透析提醒：同一提醒最多 5 个时间点，每天/每周/每月重复，支持导出系统日历 .ics
- 免责声明与来源标注：所有内容页展示

## 目录结构

```text
index.html            生产版网页入口
data/recipes.js       100 道菜谱数据
data/ingredients.js   食材库（每100克参考值，含来源标注）
assets/               PWA 图标与 favicon
manifest.webmanifest  PWA 清单
scripts/              构建、校验、测试脚本
校验报告.md            100 道菜谱与指南符合性校验报告
网页原型/              早期可点击原型（历史版本）
参考资料/              指南 PDF 与来源说明
```

## 本地运行

由于页面使用 `localStorage` 和相对路径脚本，请通过 HTTP 服务访问：

```powershell
python -m http.server 8000
```

然后打开 `http://localhost:8000`。也可以直接双击打开 `index.html`（多数功能可用）。

## 数据说明

- 营养数值为估算参考，来源：指南附录1 表1.1 及中国食物成分表常见口径，页面与报告均有标注。
- 所有内容仅供参考，不替代医生和营养师建议；正式发布前需专业审核并完成隐私政策。

## 菜谱整理

可按 [菜谱整理模板.xlsx](菜谱整理模板.xlsx) 整理新菜谱（含填写说明与食材参考表），营养数值由构建脚本自动计算。
